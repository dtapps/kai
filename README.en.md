# Kai - Cross-platform Translation & OCR Tool

> Inspired by [Bob](https://github.com/ripperhe/Bob) and [Easydict](https://github.com/tisfeng/Easydict), Kai is a menu-bar style translation + OCR desktop app primarily for macOS with Windows compatibility — featuring selection/screenshot/input translation and OCR.

[中文](./README.md)

## 1. Product Overview

A persistent system-tray / menu-bar utility that provides three core capabilities:

| Capability | Trigger | Description |
|------------|---------|-------------|
| Input Translation | Global hotkey to summon window (mac: `⌥+A` / win: `Alt+A`) | Manually enter text to translate |
| Selection Translation | Select text + hotkey (`⌥+D` / `Alt+D`), or auto popup on hover | Auto language detection |
| Screenshot Translation | Hotkey to capture a region (`⌥+S` / `Alt+S`) | Region OCR + translation |
| Silent OCR | Hotkey (`⌥+⇧+S` / `Alt+Shift+S`) | Recognize and write result to clipboard |

## 2. Tech Stack

- **Framework**: [Wails 3](https://v3.wails.io/) (Beta, Go backend + native WebView)
- **Backend**: Go 1.22+, using the Wails 3 `application` manager-style API
  - Multi-window: `translate` (main), `settings`, `selection` (popup), `screenshot`
  - `app.SystemTray` system tray, `app.Menu` native menus
  - `app.Event` in-memory IPC (no port), `app.Service` exposing Go methods to the frontend
  - `updater` auto-update (CNB / GitHub dual source, selected by UI language)
- **Frontend**: Svelte 5 (runes) + TypeScript + Tailwind CSS v4 + Vite 6 multi-entry
- **Package Management**: pnpm (frontend), Go modules
- **Local Storage**: SQLite (generated by `sqlc`) under `internal/{historystore,configstore,httplogstore}`; config and engine credentials kept separate

## 4. Feature Modules

### 4.1 Translation Engines (engine/)
Configurable API-key translation engines:
- DeepL, Google, OpenAI (incl. compatible LLMs), Baidu, Tencent, Youdao
- Unified interface `Translate(ctx, req) (*TranslateResult, error)`
- Auto language detection, side-by-side multi-engine results

### 4.2 OCR (engine + swiftbridge)
- Region capture (mac uses the `screencapture` system command, classified under the "Screen Recording" TCC permission)
- OCR engines: macOS Vision.framework (system offline OCR, zero install), Tesseract (local dependency)
- Silent mode: recognition result written to clipboard

### 4.3 Selection (selection/)
- mac: monitor system selection (Accessibility permission + clipboard polling)
- Popup: translation card near the selection position

### 4.4 Hotkeys (hotkey/ + execkey/)
- Backend global hooks, work when unfocused
- Distinguishes "registered hotkeys" from "execution keys" (e.g. copy key)

### 4.5 TTS
- System speech (mac `say`) + online TTS

### 4.6 Auto Update (updater/)
- Silent check on startup + "Check for Updates" in tray menu
- CNB / GitHub dual source, fixed single source by UI language (English → GitHub, Chinese → CNB)
- Supports nightly pre-release channel (toggle in settings)

## 6. Environment Setup

```bash
# 1. Install Wails 3 CLI
go install github.com/wailsapp/wails/v3/cmd/wails3@latest
# Verify
wails3 doctor

# 2. Install Go toolchain dependencies (sqlc / golangci-lint / govulncheck, etc.)
make tool-deps

# 3. Install frontend dependencies
make install        # equivalent to cd frontend && pnpm install

# 4. Full initialization (deps + bindings + sqlc)
make setup

# 5. Run dev (hot reload, fixed port 9247)
make dev
```

> Note: Wails 3 is currently in Beta; APIs may change. Refer to the latest docs at `v3.wails.io`.

## 7. Build & Package

```bash
# [macOS] Build release binary -> bin/Kai (no .app)
make darwin-build

# [macOS] Package -> bin/Kai.app
make darwin-package

# [macOS] Package and produce bin/Kai.dmg installer
make darwin-package-dmg

# Override version & tokens via same-named variables (CI/manual):
make darwin-package VERSION=1.2.0 BUILD_TIME=2026-08-12T00:00:00Z
```

Version and build time are passed through from variables only (`build/{darwin,linux,windows}/Taskfile.yml` `VERSION`/`BUILD_TIME`); no local fallback — callers must pass them explicitly.

## 8. Code Convention Highlights

- **Build check**: use `go build ./...` only; never `go build .` (avoids a stray `kai` binary in the repo root).
- **UI text i18n**: all user-visible text must go through `t()`; no hardcoded Chinese/English strings.
- **Frontend Runtime**: always `import { Events, Window } from '@wailsio/runtime'`; event names use constants from `frontend/src/utils/events.ts`.
- **Storage layering**: engine config (encrypted credentials) and UI preferences (`settings.json`) are strictly separated; do not mix.
- **i18n split & merge**: source files live in `internal/i18n/locales/split/**`; run `make i18n` to merge into the main files.
- **Swift bridge**: after editing `internal/swiftbridge/*.swift`, always run `make swift-build` to recompile the static library.
